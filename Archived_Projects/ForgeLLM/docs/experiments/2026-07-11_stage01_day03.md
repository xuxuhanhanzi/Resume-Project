## 7. 失败与异常

- 第一次质量检查发现 `structured_logging.py` 有一处行长超限，已调整格式；
- 第一次 mypy 检查发现解析配置字典类型过宽，已将 `RunConfig.as_dict()` 改为显式 `str | int` 映射；
- 初版敏感键规则按子串匹配 `token`，会误伤 `tokenizer` 和 token 计数；已改为精确键/敏感后缀匹配并增加防回归测试；
- 当前 Git diff 哈希不包含未跟踪文件内容，因此 dirty 状态下只作为辅助信息，正式 Release 必须在干净 commit 上复现。
