# ForgeMM B2：语言注意力 + FFN QLoRA 实验计划

## 1. 阶段目标

建立 B1 的直接对照组，判断扩大语言侧 LoRA 容量是否比“仅注意力投影”更适合 ChartQA 的图表数值问答。

## 2. 假设

ChartQA 不只要求从视觉 token 中选择信息，还包含数值、比较和关系变换。B1 只适配注意力投影，可能能够改变信息路由，却缺少调整语言模型非线性变换的容量。把 LoRA 扩展到 FFN 的 `gate_proj/up_proj/down_proj`，可能更有利于学习这些任务映射。

这只是待验证假设，不预设 B2 一定优于 B1。

## 3. 唯一主变量

- B1：`q_proj/k_proj/v_proj/o_proj`。
- B2：B1 的四个注意力投影，加上 `gate_proj/up_proj/down_proj`。

视觉编码器、视觉 merger 和底座权重仍全部冻结。

## 4. 固定项

- 模型：Qwen2.5-VL-3B-Instruct。
- 数据：ChartQA `train_human` 前 512 条作为候选池，固定随机种子 42；验证使用 `val_human` 前 50 条。
- 目标：Answer-only SFT，只监督答案 token。
- 量化：NF4 4-bit，FP16 compute。
- LoRA：rank 8，alpha 16，dropout 0。
- 优化：AdamW，学习率 `2e-4`，5 步 warmup + cosine decay。
- 训练：50 个优化步，每步梯度累积 4 次，共处理 200 条不同样本。
- 图像上限、提示词、生成参数、严格与宽松指标均与 B1 相同。

## 5. 分阶段门槛

### Smoke

- 2 个优化步，无 CUDA OOM 或非有限 loss。
- 所有可训练参数只属于语言注意力或语言 FFN 的目标 LoRA。
- 所有目标 LoRA-B 张量发生非零更新。
- Adapter 保存后目标模块集合与配置一致。

首次 smoke 在训练前被边界断言中止：PEFT 使用短名 `gate_proj` 时同时命中了视觉编码器的同名模块。正式实现改为完整语言层路径正则，并保留该失败产物作为边界检查有效性的证据。

### 受限正式运行

- Smoke 通过后才运行 50 步。
- 第 25、50 步保存检查点并验证。
- 首要指标是归一化严格准确率；ChartQA 5% 数值宽松准确率仅作辅助。
- 与 B1 的 46% 第 0 步、42% 第 50 步严格准确率直接比较。

## 6. 声明边界

50 条验证样本中每条对应 2 个百分点，因此 B2 即使小幅领先也只能作为下一阶段选择依据，不能直接写成稳定的最终提升。若 B2 有希望，需要在更大验证集与多随机种子上复核。
