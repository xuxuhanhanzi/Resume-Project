# ForgeMM B3：低学习率 Attention QLoRA 实验计划

## 1. 阶段目标

检验 B1/B2 在小规模 Answer-only SFT 中的验证性能退化，是否主要由峰值学习率过高、更新过强导致。

## 2. 假设

B1 使用 `2e-4` 时，50 条固定验证集严格准确率从 46% 降到 42%。B2 扩大参数范围后进一步降到 40%。两者都出现“修正少量错误，同时破坏更多原本正确答案”的现象。

B3 假设：保持较小的 B1 Attention LoRA 边界，将峰值学习率降低到 `5e-5`，可以减少对底座已有能力的扰动。

## 3. 唯一主变量

- B1：峰值学习率 `2e-4`。
- B3：峰值学习率 `5e-5`。

## 4. 固定项

- 模型：Qwen2.5-VL-3B-Instruct。
- LoRA：只作用于语言模型 `q_proj/k_proj/v_proj/o_proj`，rank 8，alpha 16，dropout 0。
- 训练目标：Answer-only SFT。
- 量化：NF4 4-bit，FP16 compute。
- 数据：ChartQA `train_human` 前 512 条候选池；固定种子 42；50 步共处理相同顺序的 200 条样本。
- 优化：AdamW，5 步 warmup + cosine decay；除峰值学习率外完全相同。
- 验证：固定 `val_human` 前 50 条，第 0/25/50 步评测。
- 梯度累积 4，图像预算、提示词、生成设置和评测代码不变。

## 5. 执行阶段

### Smoke

- 2 个优化步。
- loss 均为有限值，无 CUDA OOM。
- 仅语言注意力 LoRA 可训练。
- 144/144 个 LoRA-B 张量发生更新。
- 保存 Adapter 配置可复核。

### 正式受限运行

- Smoke 通过后运行 50 个优化步。
- 第 25、50 步保存不可变检查点。
- 比较原始模型、B1、B2、B3 的总体与样本级变化。

## 6. 成功门槛

- 最低门槛：第 50 步严格准确率不低于初始模型的 46%。
- 值得扩大验证：严格准确率至少 48%，同时宽松准确率不低于初始的 54%。
- 未通过：严格准确率低于 46%。此时停止继续调整 LoRA 范围和学习率，转向训练数据规模、样本分布与答案格式。

50 条验证集中每条样本对应 2 个百分点，即使达到 48% 也只视为“值得复核”，不能直接形成最终提升声明。
