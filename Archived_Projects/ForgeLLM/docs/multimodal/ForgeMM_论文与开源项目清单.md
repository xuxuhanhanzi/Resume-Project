## 2. 核验与计数规则

- 同一论文的 arXiv、会议版、项目页合并为一项；年份优先采用正式发表年份，首次公开年份可从论文页追溯。
- 2026 年仅有 arXiv 的材料统一标为“预印本，未核验正式录用”。
- A：正式论文/官方报告 + 官方代码 + 清晰复现入口；B：正式论文/官方报告但代码或资源不完整；C：高质量预印本或作者代码，仍需验证；D：社区辅助资料，不计入核心清单。
- `Strong / Medium / Background` 只评价对 ForgeMM 选题的作用，不代表论文质量。
- 论文中的分数只属于原论文；本文件没有把任何原论文指标写成 ForgeLLM 结果。
- GitHub 项目的模型权重、训练数据和第三方依赖可能采用不同许可证，采用前必须再次检查模型卡、数据卡与 LICENSE。
