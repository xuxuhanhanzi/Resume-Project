# 3 分钟演示分镜

该分镜用于录制最终演示视频。录制前运行 `docker compose up --build -d`，确认
`.\scripts\demo.ps1` 通过；画面中不得展示完整 access token 或本地密码文件。

| 时间 | 画面 | 旁白重点 |
|---|---|---|
| 00:00-00:20 | README + 架构图 | 项目边界、模块化单体选择、七服务拓扑 |
| 00:20-00:40 | Vue 首页切换四张卡片 | 人事、并发排班、薪资审批、审计监控 |
| 00:40-01:10 | Swagger 的 shift API | 行锁、重叠校验、Idempotency-Key、数据库兜底 |
| 01:10-01:40 | 运行 `scripts/demo.ps1` | 401/403/200、同 ID 重放、冲突 409、审计命中 |
| 01:40-02:05 | Surefire 记录 | MySQL 8.4 Testcontainers、7/7、缓存序列化回归 |
| 02:05-02:30 | Prometheus target + Grafana datasource | 后端指标已被真实采集，不只暴露 health endpoint |
| 02:30-02:50 | H4 k6 报告 | 1,000 条排班、100 VU、16,746 请求、0% 错误、p95 5.83 ms |
| 02:50-03:00 | 证据清单 | 强调单机认证读路径边界，不外推生产容量 |

## 录制验收

- 1920×1080、30 fps，时长 2-3 分钟；
- 终端字号可读，隐藏用户名以外的个人路径；
- 不剪掉失败重试来伪装结果；正式指标必须与 H4 JSON 一致；
- 输出文件建议命名 `hospital-workforce-demo-v1.0.0.mp4`，记录 SHA-256。
