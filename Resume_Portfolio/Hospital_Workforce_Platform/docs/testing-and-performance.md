# 测试与性能策略

## 自动化测试

- 单元测试：薪资计算、状态机、参数与领域规则。
- 模块测试：`ApplicationModules.verify()` 保证模块边界。
- 集成测试：Testcontainers 启动真实 MySQL，测试 API 和数据库迁移。
- 并发测试：多个线程创建同一员工的重叠班次，必须仅允许一个成功。
- 安全测试：验证未认证、越权和错误角色场景。

## 性能测试

`load-tests/scheduling.js` 使用 k6 模拟排班读取与创建请求。报告需记录机器配置、数据规模、虚拟用户数、持续时间、吞吐量、p95/p99、错误率、JVM 与数据库指标。

初步目标（必须由实际报告验证后才能写进简历）：100 虚拟用户、5 分钟、核心查询 p95 小于 300 ms、错误率低于 1%。
